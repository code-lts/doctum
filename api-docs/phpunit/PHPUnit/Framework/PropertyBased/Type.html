PHPUnit\Framework\PropertyBased\Type

Classes

ArrayShapeItem

An item of an array shape: a key, which may be optional, and the type of its value. The key of an item of a shape such as list{int, string} is null.

ArrayShapeType

An array shape such as array{name: string, age?: int} or list{int, string}.

DocComments

PHP discards doc comments when OPcache is active and opcache.save_comments is disabled. The doc comment of a method is then read from the source file that declares the method, so that the types in its @param tags are used regardless of the configuration of OPcache. Each file is parsed only once.

Lexer

Splits a PHPDoc type into tokens. Tokens are read on demand, so that the text that follows a type, for instance the description of a @param tag, is not lexed.

LiteralType

An integer, floating-point, or string literal, for instance 42 or 'a'.

NameContexts

Determines the namespace and the imports that apply to the declaration of a class, an interface, a trait, or an enumeration, or to a statement outside of such a declaration, the way PHP resolves names. Each file is parsed only once.

NameScope

Resolves the class names in the PHPDoc types of a method against the namespace and the imports of the file that declares the method, the same way PHPStan does. For a method that is declared in a trait, these are the namespace and the imports of the trait's file, while self and static refer to the class that uses the trait.

NamedType

A keyword such as int or non-empty-string, or a class name, optionally with generic arguments, for instance list or int<0, max>. T[] is parsed as array.

NullableType

A type written as ?T. T|null is parsed as UnionType.

ParameterTypes

The types of the parameters of a method as they are declared in its doc comment with the tags param, phpstan-param, and psalm-param.

SourceFileParser

Parses the source files from which the doc comments of methods and the namespaces and imports that apply to declarations are read. The nodes of the file that was parsed last are kept, so that a file whose doc comments and namespaces and imports are both needed, one after the other, is parsed once.
