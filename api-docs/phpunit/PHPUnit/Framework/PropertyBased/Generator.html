PHPUnit\Framework\PropertyBased\Generator

Classes

AbstractGenerator

A generator builds a value from the choices it draws from a choice source.

ArrayGenerator

Generates arrays with keys and values of the given generators. A key that is already present in the array is not added again.

BooleanGenerator

Generates false (choice 0) and true (choice 1).

BytesGenerator

Generates arbitrary binary strings. Each byte is one choice, its value.

CodePointRanges

The code points of the characters that a string generator chooses from, given as ranges. The ranges are sorted, ranges that overlap or adjoin each other are merged, and surrogates, which are not characters, are left out.

ConstantGenerator

Generates the same value without drawing a choice.

DateTimeGenerator

Generates points in time from a minimum to a maximum, in one of the time zones, as DateTimeImmutable objects.

DeferredGenerator

A generator that is derived from a type only when it generates its first value, by the deriver of the choice source. This way, the generators that the test case class of the property registers for types are used, even for the generators that are created while an example is generated.

DomainNameGenerator

Generates domain names of letters, digits, and hyphens (RFC 1123) in lowercase, without a trailing dot.

ElementsGenerator

Generates one of the given values. The choice is the index of the value, so the first value is the simplest one.

EmailAddressGenerator

Generates email addresses (RFC 5321) of at most 254 characters, with a local part of at most 64 characters.

FilteredGenerator

Generates values of the given generator until one satisfies the predicate.

FlatMappedGenerator

Generates a value of the given generator, and then a value of the generator that the mapper returns for it.

FloatGenerator

Generates floating-point numbers from three choices: the sign (0 for positive), whether the magnitude is an integer (0) or not (1), and the magnitude.

IntegerGenerator

Generates integers in the range [$minimum, $maximum]. The choice 0 stands for the value closest to zero.

Ipv4AddressGenerator

Generates IPv4 addresses of a network in dotted decimal notation.

Ipv6AddressGenerator

Generates IPv6 addresses of a network in the canonical text representation of RFC 5952: lowercase hexadecimal digits without leading zeros, the first longest run of at least two groups of zeros compressed to "::", and the last 32 bits of an IPv4-mapped address in dotted decimal notation.

ListGenerator

Generates lists of the values of a generator. In a list of unique elements, no element equals another one: an element that does is generated again.

MappedGenerator
NullableGenerator

Generates null (choice 0) or a value of the given generator (choice 1).

ObjectGenerator

Generates objects of a class with new, using an argument of the respective generator for each parameter of the class's constructor for which there is a generator. The arguments are passed by the names of the parameters, so that the constructor uses the default value of a parameter for which there is no generator, also when there is one for a parameter after it.

OneOfGenerator

Generates a value of one of the given generators. The first choice is the index of the generator, so the first generator is the simplest one.

RecordGenerator

Generates arrays with the given keys and a value of the respective generator for each of them.

RegularExpressionGenerator

Generates strings that a regular expression matches, from the nodes that it was parsed into. A string that the regular expression does not match, for instance because an anchor is neither at its start nor at its end, is rejected.

StringGenerator

Generates valid UTF-8 strings. Their length is the number of characters (code points), not the number of bytes.

TupleGenerator

Generates lists that consist of one value of each of the given generators.

UrlGenerator

Generates URLs (RFC 3986) with an authority: a scheme, optional user information, a host, an optional port, a path, an optional query, and an optional fragment.

UuidGenerator

Generates UUIDs (RFC 9562) in their canonical form.
