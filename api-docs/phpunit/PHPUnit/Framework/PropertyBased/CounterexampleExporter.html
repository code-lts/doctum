CounterexampleExporter

final class CounterexampleExporter (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Exports the arguments of a counterexample as PHP expressions that can be copied into a data provider for a regression test.

Scalars and arrays are exported as PHP literals, the cases of enumerations as constant expressions such as Currency::EUR, objects that generators created with new as the expression that created them, and points in time as new DateTimeImmutable('...'), with their time zone when it has a name, and the objects whose properties are all readonly and promoted constructor parameters, such as value objects and domain events, as the expression that creates them with the values of their properties. Class names are written the way the file that declares the property imports them, or fully qualified when it does not import them. Other objects are exported with sebastian/exporter.

A value that cannot be exported as a PHP expression, because exporting it raises an exception, is exported with sebastian/exporter, like other objects, rather than aborting the test run. This holds for every value that is part of another one, such as an element of an array or an argument of a constructor, on its own.
