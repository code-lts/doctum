PhpDocumentorParserTypeRecoveryTest

class PhpDocumentorParserTypeRecoveryTest extends TestCase (View source)

Regression tests for {PhpDocumentorParser} faithfully preserving generic types that phpDocumentor's Collection value object collapses.

phpDocumentor models a collection as Base<value> or Base<key, value> only, so generics with more than two type arguments are truncated (and reordered): e.g. \Generator<int, list<string>, void, void> was rendered as \Generator<void,void>. The parser recovers such types verbatim from the raw docblock while leaving the types phpDocumentor handles correctly untouched.
