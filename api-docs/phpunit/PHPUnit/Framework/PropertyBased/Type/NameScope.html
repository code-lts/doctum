NameScope

final class NameScope (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Resolves the class names in the PHPDoc types of a method against the namespace and the imports of the file that declares the method, the same way PHPStan does. For a method that is declared in a trait, these are the namespace and the imports of the trait's file, while self and static refer to the class that uses the trait.

The file is only parsed when a name is resolved against its namespace and imports, which most PHPDoc types do not require, so that the files of the properties are not parsed while the test suite is built.
