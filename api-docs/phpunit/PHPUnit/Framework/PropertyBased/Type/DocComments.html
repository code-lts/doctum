DocComments

final class DocComments (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

PHP discards doc comments when OPcache is active and opcache.save_comments is disabled. The doc comment of a method is then read from the source file that declares the method, so that the types in its @param tags are used regardless of the configuration of OPcache. Each file is parsed only once.

Returns the doc comment of the method, which is read from the source file that declares the method when PHP has discarded it, or false when the method does not have one.

static array
ofPromotedParameters(ReflectionMethod $constructor)

Returns the doc comments of the promoted parameters of the constructor that have one, by the names of the parameters. They are read from the source file that declares the constructor when PHP has discarded them, where only a doc comment that precedes the parameter, its attributes and modifiers included, is found.
