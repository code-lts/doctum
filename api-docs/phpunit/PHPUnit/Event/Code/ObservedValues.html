ObservedValues

final class ObservedValues (View source)

A label with which TestCase::observe() observed numeric values of examples of a property, with the number of values that were observed with it and their statistics.

The median and the 90th percentile are values that were observed: the smallest ones that at least 50 and 90 percent of the values are not greater than.
