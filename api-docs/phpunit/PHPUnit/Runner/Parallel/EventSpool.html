EventSpool

final class EventSpool (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Keeps the events that units streamed before it is their turn in the release sequence, and what their workers wrote to their standard output and to their standard error before they streamed them, in a temporary file rather than in memory.

The events of a unit are held back until every unit that precedes it in suite order has been released. A single slow test class can therefore hold back the events of most of a test suite, and the events of a test are big: each of them carries the value object of the test and telemetry information. Held back as objects, the events of a few thousand tests need more memory than a PHP process is commonly allowed to use.

The worker that streamed the events already wrote them to a file once. They are written to a file again here, and read back, collection by collection, when they are forwarded: what is held in memory for a unit that waits for its turn is where its events are in that file.

The file is created when the first events are held back, and it is deleted by PHP when it is closed or when the process ends. It is emptied whenever no events are held back anymore, so that it does not grow with the number of events that were held back during the test run, only with the number that are held back at the same time.
