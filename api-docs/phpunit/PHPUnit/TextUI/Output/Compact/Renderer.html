void printHeader(string $type, string $title)

Prints the header line that starts a record ("--- TYPE: title").

The header must always be exactly one line so that a user-supplied title cannot start a record of its own. Line feeds and carriage returns in the title are therefore made visible as escape sequences, in addition to the control characters that Sanitizer::sanitizeControlCharacters() makes visible.
