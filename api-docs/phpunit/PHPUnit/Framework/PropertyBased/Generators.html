static ValueGenerator fromRegularExpression(string $regularExpression)

Generates strings that the given regular expression, with its delimiters and modifiers, matches as a whole, for instance '/\A[a-z]+-\d{2,4}\z/'.

Literal and escaped characters, the dot, character classes, the escape sequences \d, \D, \w, \W, \s, \S, \h, \H, \v, and \V, quantifiers, groups, alternation, \Q...\E, comments, and all modifiers are supported. Anchors and the other assertions that consume no characters, such as ^, $, and \b, are supported where they hold for the strings that are generated, at their start or end, for instance; an example is rejected when the regular expression does not match the generated string. Lookahead and lookbehind assertions, backreferences, recursion, conditional subpatterns, inline options, and Unicode properties are not supported.

With the u modifier, the strings are valid UTF-8, and \d, \w, and \s, as well as \D, \W, and \S, only generate ASCII characters. Without it, the strings are binary strings: the dot and negated character classes can generate any byte. The simplest string consists of the simplest characters, the minimum number of repetitions, and the first alternatives.

static ValueGenerator lists(ValueGenerator $elements, int $minimumSize = 0, int|null $maximumSize = null, bool $recursive = false, bool $unique = false)

Generates lists of $minimumSize to $maximumSize elements.

$recursive must be true when the elements can contain lists of this generator, for instance in the generator that is registered with

[GeneratorFor] for a class whose objects contain a list of objects of

the same class: another element is then added less often, so that the generated values stay small. A generator that is derived from the type of a parameter does this on its own.

When $unique is true, no element of a list equals another one. Objects are equal when they are of the same class and assertEquals() considers them equal, other values when they are identical, and NAN equals NAN. The example is rejected when $elements does not generate enough different values for $minimumSize.

static ValueGenerator combine(Closure $combiner, ValueGenerator $first, ValueGenerator|null $second = null, ValueGenerator|null $third = null, ValueGenerator|null $fourth = null, ValueGenerator|null $fifth = null, ValueGenerator|null $sixth = null, ValueGenerator|null $seventh = null, ValueGenerator|null $eighth = null, ValueGenerator ...$further)

Generates the values that $combiner returns when it is called with one value of each of the given generators, in their order: an object that is built from generated values, for instance.

Unlike with flatMap(), the choices of the values do not depend on each other, so a counterexample shrinks as well as the values of each of the generators do. Use flatMap() only when a generator depends on a value that was generated before.

$combiner must take the value of each of the generators: it must have as many parameters as generators are given, or be variadic, and must not require more arguments than generators are given.

The types of the parameters of $combiner are checked against the types of the values of the first eight generators by static analysis. The values of further generators are passed to $combiner as well, but their types are not checked, and static analysis only accepts a $combiner that takes them with a variadic parameter, not one that declares a ninth parameter.

static ValueGenerator deferred(Closure $generator)

Generates the values of the generator that $generator returns, which is called when the first value is generated rather than now. This way, a generator can refer to itself, for values that contain values of the same kind:

$values = Generators::deferred( static function () use (&$values): ValueGenerator { return Generators::oneOf( Generators::integers(), Generators::lists($values, recursive: true), ); }, );

A generator that refers to itself has to make a choice before it does, as oneOf() does here, and it has to pass true for $recursive to lists(), arrays(), and nullable(), so that the generated values stay small.

static ValueGenerator emailAddresses(bool $quotedLocalParts = false, bool $ipAddressLiterals = false)

Generates email addresses (RFC 5321) of at most 254 characters, with a local part of at most 64 characters and a domain name from domainNames().

The local part consists of the characters that RFC 5322 allows in an atom (letters, digits, and !#$%&'*+-/=?^_`{|}~) and of dots, but neither starts nor ends with a dot nor has two dots in a row. These email addresses pass filter_var() with FILTER_VALIDATE_EMAIL.

With $quotedLocalParts, some local parts are quoted strings of printable ASCII characters, including spaces, in which quotes and backslashes are escaped with a backslash. With $ipAddressLiterals, some domains are address literals of an IPv4 or an IPv6 address, for instance [192.0.2.1] or [IPv6:2001:db8::1].

Local parts of 64 characters and email addresses of 254 characters are generated often. The simplest email address is a@a.aa. With $ipAddressLiterals, the counterexample of a property whose outcome does not depend on the domain can have the domain [0.0.0.0] or [IPv6:::] instead, which take fewer choices than a.aa.

static ValueGenerator urls(array $schemes = ['http', 'https'], bool $userInformation = false)

Generates URLs (RFC 3986) of the schemes in $schemes with an authority: a scheme, a host, an optional port, a path, an optional query, and an optional fragment. With $userInformation, some URLs have user information, a user name and an optional password, in front of the host.

The host is a domain name from domainNames(), an IPv4 address, or an IPv6 address in brackets. The port is biased towards 1, 65535, and common default ports. The path consists of segments, of which the last one is empty for a trailing slash, and is empty often. The query consists of key-value pairs, which are separated by "&".

The URLs are normalized, as far as their syntax goes: the scheme and the host are lowercase, characters are percent-encoded only when they have to be, the hexadecimal digits of their encoding are uppercase, and no segment is "." or "..". Reserved characters, spaces, and characters that are encoded with two, three, and four bytes in UTF-8 are percent-encoded often. These URLs pass filter_var() with FILTER_VALIDATE_URL, except for some with user information: filter_var() rejects a percent-encoded byte in the user information whose first hexadecimal digit is a letter, such as %C3 of ä.

The first scheme is the simplest one, and the simplest URL is http://a.aa by default. An IP address takes fewer choices than a.aa, though, so that the counterexample of a property whose outcome does not depend on the host can have the host 0.0.0.0 or [::] instead.

static ValueGenerator dateTimes(DateTimeInterface|null $minimum = null, DateTimeInterface|null $maximum = null, array $timezones = ['UTC'], bool $microseconds = false)

Generates points in time from $minimum to $maximum as DateTimeImmutable objects in one of the time zones in $timezones, which are given as their identifier, their abbreviation, or their offset from UTC. By default, the points in time are from 0001-01-01 00:00:00 UTC to 9999-12-31 23:59:59 UTC, in UTC, and without microseconds.
