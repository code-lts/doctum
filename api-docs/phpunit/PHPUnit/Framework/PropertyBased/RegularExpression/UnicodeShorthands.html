UnicodeShorthands

final class UnicodeShorthands (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

The characters that an escape sequence such as \w, or a POSIX class such as [:alpha:], matches in a regular expression with the u modifier.

The u modifier makes them match characters by their Unicode properties, so that \w matches letters such as é, and \d the digits of all scripts. Which characters these are depends on the version of Unicode that PCRE was built for, and on the version of PCRE. PCRE is therefore asked for them: it looks for the characters that the escape sequence or the POSIX class matches in all Unicode scalar values.

This is only done when a regular expression needs these characters, and once for each escape sequence and each POSIX class, as it takes some tens of milliseconds.
