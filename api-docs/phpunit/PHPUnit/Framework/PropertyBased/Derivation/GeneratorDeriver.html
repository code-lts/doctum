GeneratorDeriver

final class GeneratorDeriver (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Derives generators from the types of parameters: from the type in the parameter's @param tag (including @phpstan-param and @psalm-param) if there is one, from the type in the @var tag (including @phpstan-var and @psalm-var) of the doc comment of a promoted constructor parameter that has no @param tag, and from its native type declaration otherwise. The tags are read from the source file when OPcache has discarded the doc comments.

A generator that the test case class registers for a class with

[GeneratorFor] is used for every value of exactly that class, including

the arguments for the constructors of other classes.

Objects of other concrete classes are created with new, using arguments that are generated for the parameters of the constructor, recursively. A parameter that has a default value does not receive an argument when no generator can be derived for its type.

PROBABILITY_OF_RECURSION

The probability that a nullable value or a collection that can contain an object of a class that is being constructed contains it, which is smaller than usual so that the recursive construction ends soon. The collections and nullable values that are created with Generators for recursive values use it, too.
private UNSUPPORTED_KEYWORDS

private KEYWORDS_THAT_CAN_BE_CLASS_NAMES

The keywords of PHPDoc types that PHP does not reserve, so that a class can have one of them as its name. Like in PHPStan, such a name refers to the class when a class of that name exists in the namespace, or is imported in the file, of the doc comment. A class in the namespace has to be written as it is declared, Resource rather than resource, for instance, as only the name of an imported class is resolved to the name with which it is declared. The names that PHP reserves, such as int and iterable, and the ones that contain a hyphen, such as positive-int, cannot be the names of classes.
private KEYWORDS_OF_ARRAY_KEYS

The keywords of the types whose values are integers or strings, which are the only values that PHP uses as the keys of an array as they are.
