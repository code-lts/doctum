Counterexample
counterexample()

The minimal counterexample, or the explicit example that falsified the property. An explicit example is not shrunk, so there are no shrinking attempts for it.

array
otherFalsifications()

The other ways in which the property was falsified while the counterexample was shrunk, each with the simplest counterexample that falsified it that way, in the order in which they were first seen. It is empty when the property was falsified by an explicit example, which is not shrunk.

int
numberOfReplays()

How often the example that first falsified the property was replayed before its counterexample was shrunk, to tell whether it falsifies the property again. Replays whose generators did not generate the same arguments are not counted. It is 0 when the property was falsified by an explicit example, which is not replayed, or by an example that exceeded its time limit, which would take as long as the time limit again.

int
numberOfReproductions()

How many of the replays of the example that first falsified the property falsified it again in the same way. When this is less than the number of replays, the outcome of the property does not depend on its arguments alone.
