PHPUnit\Runner\Parallel

Classes

CommandStream

The wire format with which the parent process sends commands to a worker on the worker's control channel, its standard input.

CompletedWorkUnit

The outcome of a WorkUnit that a worker has finished: the serialized result envelope written by the worker, together with the unit it belongs to and the nonce that authenticates the envelope.

DataProviderSuiteDescriptor

The descriptor of the suite that aggregates the tests of a data provider method. Its members are described recursively so that the suite travels to the worker as a suite and emits, inside the worker, the event envelope that nests its tests in the logger output.

DispatchQueue

The units of a chunk that have not been dispatched yet.

EventSpool

Keeps the events that units streamed before it is their turn in the release sequence, and what their workers wrote to their standard output and to their standard error before they streamed them, in a temporary file rather than in memory.

EventStream

The wire format with which a worker streams events to the parent process while a unit of work is still running.

PassedTestsRecorder

Records, inside a worker process, that a test method whose test is run more than once passed, so that the tests of the same unit that depend on it can run.

PersistentWorker

A worker process that boots PHPUnit once and then executes an arbitrary number of tests, each in response to a command received on its control channel (its standard input). A unit of work is a whole test class; the worker reconstructs it from the dispatched command, runs it, and reports the result back through the filesystem (see dispatch() and poll()).

PhptRunner

Runs PHPT tests concurrently, each as its own child process, in the main PHPUnit process.

PhptWorkUnit

A unit of work for a single PHPT test, identified by the path of its .phpt file. A PHPT test is not a PHPUnit\Framework\TestCase and carries no test data, so the worker reconstructs it from nothing more than this file path.

ProcessBudget

The number of units that may execute concurrently, shared by everything that runs units side by side in a parallel run.

PropertySuiteDescriptor

The descriptor of the suite that checks a property. The suite travels to the worker as a suite so that the property is checked inside the worker: its examples are generated, run, and shrunk there, and only the events that the property is reported with travel back.

RepeatSuiteDescriptor

The descriptor of the suite that aggregates the repetitions of a repeated test method. All repetitions are described; the suite travels to the worker as a suite so that its failure threshold is applied inside the worker, which skips the remaining repetitions once the threshold is exceeded.

ResultAggregator

Collects the results that the workers produce and replays them into the parent process' event subsystem.

RetrySuiteDescriptor

The descriptor of the suite that aggregates the attempts of a retried test method. Only the first attempt is described; the suite travels to the worker as a suite so that the additional attempts are built and run inside the worker, from the same descriptor.

Scheduler

Orders the units of a chunk for dispatch: the longest first.
