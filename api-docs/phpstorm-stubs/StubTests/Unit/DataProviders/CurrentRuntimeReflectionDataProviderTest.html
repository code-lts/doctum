testItDoesNotReturnUsersFunctions()

getReflectionFunctions() returns get_defined_functions()['internal'], an integer-keyed list of names. This previously asserted assertFalse(array_key_exists('my_custom_function', ...)), which is unconditionally true for a list and so would have passed even if the provider returned every user-defined function. The value must be searched, not the key.
