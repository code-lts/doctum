Counterexample

final class Counterexample (View source)

An example that falsified a property: the choices from which its arguments were generated, its arguments, the values that it drew, and the steps of its state machine, exported as PHP code, or the explicit example that falsified the property.

array
choiceSequence()

The choices from which the arguments of the counterexample were generated. It is empty for an explicit example, whose arguments are not generated.

array
arguments()

The arguments of the counterexample, exported as PHP code, by the name of the parameter they were passed to.

null|int|string
explicitExample()

The name of the explicit example, specified with #[TestWith] or

[TestWithJson], that is the counterexample, or its number among the

explicit examples for which no name is specified. Null when the counterexample was generated.

array
drawnValues()

The values that the counterexample drew with draw(), in the order in which they were drawn. It is empty for an explicit example, for which values cannot be drawn.

array
steps()

The steps of the state machine that the counterexample ran with runStateMachine(), written as PHP code that calls the methods of the state machine, which is referred to as $machine, or as $stateMachine when a parameter of the property is named machine, in the order in which they were taken, followed by the invariant that failed, if one did. It is empty when the counterexample did not run a state machine.

string|null
formatted()

What the method that is specified with #[CounterexampleFormatter] or

[CounterexampleFormatterExternal] returned for the arguments of the

counterexample, null when no such method is specified or when it returned an empty string.
