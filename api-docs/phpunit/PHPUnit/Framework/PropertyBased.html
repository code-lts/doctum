Classes

CannotCreateObjectException

Reports that an object of a class, for which a generator was derived from the types of the parameters of its constructor, cannot be created because the constructor does not accept the arguments that were generated for it: the constructor of a value object that validates its arguments, for instance.

CannotDeriveGeneratorException

Thrown when no generator can be derived from a type. The message names the parameter and the type that could not be handled.

ChoiceSource

Provides the choices from which generators build the arguments of an example, and records them as the example's choice sequence.

Constructions

The objects that generators created with new while an example was generated, together with the arguments that were passed to their constructors. An object is exported as the expression that created it, even when its state was changed afterwards.

CounterexampleExporter

Exports the arguments of a counterexample as PHP expressions that can be copied into a data provider for a regression test.

DrawnValues

Draws the values that the body of an example of a property draws with TestCase::draw(), and the steps of the state machine that it runs with TestCase::runStateMachine(), from the choice source that generated its arguments, so that they are replayed and shrunk together with the arguments.

EventAggregator

Aggregates the events of the examples of a property, which are collected rather than dispatched, into the events that are reported for the property.

ExampleRejectedByAssumptionException

Thrown by TestCase::assume(), and by TestCase::draw() when no value can be generated, to discard the current example of a property.

ExampleRejectedException

Thrown while the arguments for an example are generated when the example has to be discarded, for instance because a filter could not be satisfied.

ExampleResult

The result of an example of a property that was run on its own rather than while the property was checked: whether it passed, was rejected, skipped, or marked as incomplete, falsified the property, or was aborted without checking the property, and the choices from which its arguments and the values that it drew were generated.

ExampleRunner

Builds and runs the examples of a property: it creates the test case of an example, generates its arguments from a source of choices, runs it with its events collected, handles the issues that are triggered while values are generated as issues of the property, and exports arguments as PHP code.

ExplicitExample

An example of a property whose arguments are specified with #[TestWith] or

[TestWithJson] instead of being generated.

Falsification

How an example falsified a property.

FalsificationReport

How a property was falsified, as it is reported: with the Test\PropertyFalsified event and as part of the failure or error of the property.

FalsificationReporter

Reports how a property was falsified: by an explicit example, whose failure or error is reported as it is, or by a generated example, which is replayed to tell whether it falsifies the property again, whose counterexample is shrunk, and whose minimal counterexample is replayed, as are the simplest counterexamples of the other ways in which the property was falsified while it was shrunk.

FalsifyingIssues

Tells which of the issues that an example triggered falsify its property.

FlakyPropertyException

Reports a property that was falsified by an example, but not when that example was replayed, or not when its minimal counterexample was replayed.

GeneratorMethod

A public static method that returns a generator: a method that is registered with #[GeneratorFor], or one that is specified with #[ForAll] or

[ForAllExternal].

GeneratorMethodValidator

Validates the classes and the methods with which generators are created: the generator that is specified with #[ForAll] or #[ForAllExternal] for a parameter, the classes that are used with #[UseGenerators], and the methods that are registered with #[GeneratorFor].

GeneratorRefersToItselfException

Reports a generator that refers to itself before it makes a choice, so that generating a value with it would recurse infinitely.

GeneratorResolver

Resolves the generators of the parameters of a property from its definition: the generators that were derived from the types of the parameters, the generator methods and closures that are specified with

[ForAll], and the generators that are registered for classes.

Generators

Factory for the generators that the parameters of properties are generated with.

InvalidGeneratorArgumentException

Thrown when a generator is created or composed with invalid arguments.

InvalidGeneratorMethodException

Thrown when a generator cannot be created with the class or the method that it is specified with. The message is the reason, which the caller reports for the property or the state machine that specifies the generator.

InvalidPropertyException

Thrown when a property cannot be checked, for instance because no generator can be determined for one of its parameters.

InvalidStateMachineException

Thrown when a state machine cannot be run, for instance because it has no rule or a pool from which one of its rules takes a value is not produced by any of them.

InvalidTypeException

Thrown when a PHPDoc type cannot be parsed.

Observations

The numeric values that the examples of a property observed with TestCase::observe(), by their label, and their statistics.

PropertyDefinition

A property after its metadata has been validated: the generator for each of its parameters that is derived from its type or where it comes from otherwise, its explicit examples, the minimum percentages of its examples that are required to be classified with labels, and the methods of its test case class that are registered with #[GeneratorFor].

PropertyDefinitionBuilder

Validates the metadata of a property before it is checked.

PropertyExample

An example of a property: the arguments with which its test method is called, and what the example records while it runs, with assume(), draw(), runStateMachine(), classify(), observe(), and target() of TestCase, which delegate to it, and the throwable that ended it.

PropertyStatistics

What the examples of a property that were generated and checked while the property was checked amount to: how many were checked and rejected, and why, how they were classified, what they observed, and the assertions that they performed. From these it decides whether further examples are generated and whether the property is considered risky, and why.

ValueGeneratorNotSupportedException

Thrown when an object of a class that implements ValueGenerator but was not created by PHPUnit is used as a generator.
