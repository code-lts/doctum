ExampleRunner

final class ExampleRunner (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Builds and runs the examples of a property: it creates the test case of an example, generates its arguments from a source of choices, runs it with its events collected, handles the issues that are triggered while values are generated as issues of the property, and exports arguments as PHP code.

at line 345
string|null format(Closure $arguments, EventAggregator $events)

What the method that is specified with #[CounterexampleFormatter] or

[CounterexampleFormatterExternal] returns for the arguments of a

counterexample that is reported, null when no such method is specified or when it returns an empty string.

The formatter is called with arguments of its own, which $arguments returns, rather than with the ones that an example is run with: an example cannot change what is formatted, and a formatter that changes the state of an argument, or consumes an iterator, cannot change what an example is run with. $arguments is only called when a formatter is specified.

The issues that the formatter triggers are handled as issues of the property and recorded with $events, and the output that it prints is discarded.

A formatter that raises an exception or does not return a string does not keep the counterexample from being reported, and neither does an exception that is raised while its arguments are generated: what went wrong is reported in place of what the formatter should have returned.

Describes a generated example for the case that the PHP process ends while it is run, because of a fatal error, for instance: an example that ends the process is neither reported for the property nor shrunk, so this is the only report of its arguments, of the values that it drew, and of the steps of its state machine.
