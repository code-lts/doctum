PropertyFalsifiedToStringMapper

final class PropertyFalsifiedToStringMapper (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Describes how a property was falsified, with its minimal counterexample written as PHP code that can be copied into a data provider, for instance:

Property falsified after 2 examples, counterexample shrunk in 17 steps:

    $money = new Money(amount: 1, currency: Currency::EUR);
    $parts = 2;

The values that the minimal counterexample drew with draw() follow its arguments, numbered in the order in which they were drawn and described by their labels:

Property falsified after 8 examples, counterexample shrunk in 2 steps:

    $size = 1;

    Draw 1 (list): [5]
    Draw 2 (index): 0

The steps of the state machine that the minimal counterexample ran with runStateMachine() follow, as calls of the methods of the state machine, which is referred to as $machine, or as $stateMachine when a parameter of the property is named machine:

Property falsified after 3 examples, counterexample shrunk in 25 steps:

    $accounts1 = $machine->open();
    $machine->deposit(account: $accounts1, amount: 1);
    $machine->projectionMatchesTheModel(); // invariant failed

When the property was falsified in other ways while the counterexample was shrunk, the simplest counterexample for each of them follows:

Property also falsified by RuntimeException at /path/to/FooTest.php:12 with this counterexample:

    $size = 3;

A property can also be falsified by one of its explicit examples, which is reported with its arguments:

Property falsified by explicit example "minus one":

    $value = -1;

static Generator mapExampleThatEndedTheProcess(Counterexample $example, Closure $formatted)

Describes the example of a property that was run when the PHP process ended, because of a fatal error, for instance, with its arguments, the values that it drew until then, and the steps of its state machine that were taken until then.

The description is generated in parts, which are to be separated by an empty line, so that a part can be printed before the next one is worked out: the counterexample formatter is only called once the arguments have been generated, as the PHP process is ending and a formatter that fails as well would otherwise leave nothing of the example.
