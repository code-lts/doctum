EventAggregator

final class EventAggregator (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Aggregates the events of the examples of a property, which are collected rather than dispatched, into the events that are reported for the property.

Exactly one sequence of events from Test\PreparationStarted to Test\Finished is reported for a property: the one of a single example, the skeleton, whose Test\PreparationStarted and Test\Prepared events are replaced with those of the first example, so that the duration of the property covers all of its examples. The issues and the Test\ConsideredRisky events of all examples that were checked are reported within that sequence, those of the skeleton included, and so is the output that they printed, as one Test\PrintedUnexpectedOutput event. The issues of the examples that were rejected are reported as well, and so are the TestRunner\GarbageCollectionTriggered events of all examples, those of the shrinking attempts included. A Test\ConsideredRisky event and an issue of PHPUnit's own are reported once per message, and the number of assertions is the one that is passed in.

Only the Test\AdditionalInformationProvided events of the skeleton are reported, and only for a property that did not pass: the additional information is the one that was provided for the example whose outcome is reported, the minimal counterexample, for instance. For a property that passed, it would be the additional information of an arbitrary example.
