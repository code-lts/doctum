PHPUnit\Framework\PropertyBased\StateMachine

Classes

ParameterDefinition

A parameter of a step of a state machine: it receives a value from a pool (#[FromPool]), or a value of a generator, which is the one that is specified with #[ForAll] or #[ForAllExternal], or the one that is derived from its type.

StateMachineDefinition

A state machine after its metadata has been validated: the methods that are called once before its steps are taken (#[InitializeStateMachine]), its rules (#[StateMachineRule]), and its invariants (#[StateMachineInvariant]), each in the order in which it is declared, with those that a parent class declares before those that the class that extends it declares.

StateMachineDefinitionBuilder

Validates the metadata of a state machine before it is run, and creates the generators for the parameters of its steps that do not receive values from pools: the generators that are specified with #[ForAll] or #[ForAllExternal] and the generators that are derived from the types of the parameters with the deriver of the property that runs the state machine, which knows the generators that are registered for it with #[GeneratorFor].

StateMachineRunner

Runs a state machine with the choices of an example of a property, so that its steps are generated, replayed, and shrunk together with the arguments of the property.

StepDefinition

A step of a state machine: a method with #[StateMachineRule], which can be taken any number of times while its precondition holds, or a method with

[InitializeStateMachine], which is called once before the rules are taken.
