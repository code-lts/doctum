TypeParser

final class TypeParser (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Parses the PHPDoc types that generators can be derived from:

type := atom ('|' atom) atom := '?' atom | ( '(' type ')' | literal | name generic? shape? ) ('[' ']') generic := '<' type (',' type) ','? '>' shape := '{' (item (',' item) (',' '...')? | '...')? ','? '}' item := key '?'? ':' type | type

A literal is an integer, floating-point, or string literal, and a key is an identifier, an integer literal, or a string literal. Other syntax, for instance intersection types, callable types, and conditional types, cannot be parsed.
