NameContexts

final class NameContexts (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Determines the namespace and the imports that apply to the declaration of a class, an interface, a trait, or an enumeration, or to a statement outside of such a declaration, the way PHP resolves names. Each file is parsed only once.

Returns the name context that applies to the declaration of the class (or interface, trait, or enumeration) that contains the given line, or to the statement outside of such a declaration that contains it, such as the declaration of a function, or the context of the global namespace without imports when the file cannot be read or parsed or no declaration or statement contains the line.
