PropertyDefinition

final class PropertyDefinition (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

A property after its metadata has been validated: the generator for each of its parameters that is derived from its type or where it comes from otherwise, its explicit examples, the minimum percentages of its examples that are required to be classified with labels, and the methods of its test case class that are registered with #[GeneratorFor].
