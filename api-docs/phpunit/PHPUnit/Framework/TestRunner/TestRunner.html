ExampleRun runExampleOfProperty(TestCase $example, bool $collectCodeCoverage, int|null $timeLimit = null, Closure|null $describe = null)

Runs an example of a property, in the process that runs the property.

Whether the property is risky for the assertions that its examples performed, for their contribution to code coverage, or because one of them exceeded its time limit, is decided on all of its examples rather than on this one.

The message that is printed when the PHP process ends prematurely is not reset once the example has been run, only the description of the example is: the process can also end between the examples of a property, while the arguments of the next one are generated. It is reset by the caller, once the property has been checked or the example has been run on its own.

Parameters

TestCase $example
bool $collectCodeCoverage

whether code coverage is collected for the example, if it is collected at all: it is not for the shrinking attempts and the final replay of the minimal counterexample
int|null $timeLimit

the time limit of the example in seconds, which is enforced instead of the configured one whenever a time limit can be enforced, or null for the configured one
Closure|null $describe

describes the example, which is printed when the PHP process ends while the example is run
