array dataSets()

Whether a test method has data sets, keyed by method name.

The name of a test that has no data set is the name of its method, which makes it possible to decide whether a filter for the name of a test can select it. The name of a data set is only known once the data provider has been invoked, so a method that has data sets cannot be decided.
