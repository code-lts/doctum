GeneratorMethodValidator

final class GeneratorMethodValidator (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Validates the classes and the methods with which generators are created: the generator that is specified with #[ForAll] or #[ForAllExternal] for a parameter, the classes that are used with #[UseGenerators], and the methods that are registered with #[GeneratorFor].
