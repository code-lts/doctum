Parser

final class Parser (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Parses a regular expression, with its delimiters and modifiers, into the nodes from which strings are generated that the regular expression matches as a whole.

Supported are literal characters, escaped characters, the dot, character classes with ranges, negation, escape sequences, and POSIX classes, the escape sequences \d, \D, \w, \W, \s, \S, \h, \H, \v, and \V, quantifiers, lazy and possessive ones included, capturing, non-capturing, named, atomic, and branch reset groups, alternation, comments, \Q...\E, and all modifiers. Anchors and the other assertions that consume no characters, such as ^, $, \A, \z, and \b, are generated as the empty string.

Not supported are lookahead and lookbehind assertions, backreferences, recursion, conditional subpatterns, inline options, Unicode properties, and the other escape sequences that do not stand for a character or a class of characters.

The escape sequences \d, \w, and \s only generate ASCII characters, which they match with and without the u modifier, and \D, \W, and \S, as well as negated POSIX classes, only generate ASCII characters with the u modifier, because it makes them not match other characters, such as letters, that they do not match without it. For the same reason, a negated character class that contains one of them, such as [^\W_], only generates ASCII characters with the u modifier.

A negated character class that contains \d, \w, \s, or a POSIX class, such as [^\w], generates the characters that these do not match. With the u modifier, PCRE is asked for the characters that they match, so that the other ones, among them characters that are not ASCII characters, are generated.
