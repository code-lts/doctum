ChoiceSource

final class ChoiceSource (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Provides the choices from which generators build the arguments of an example, and records them as the example's choice sequence.

Drawing the choices, at random or by replaying a choice sequence, and avoiding examples that were generated before with a choice tree is left to the choice source of sebastian/choice-sequence, so that the choices of an example are drawn and replayed in the same way wherever that library is used.

It also provides the deriver for the generators that are derived from types while the example is generated, keeps track of the objects that are being generated, so that recursive construction can be limited, and records how objects were constructed, so that they can be exported.

mixed suggest(array $candidates, float $probability)

Returns, while choices are drawn at random, one of the candidates with the given probability, and null otherwise.

No choice is drawn: a generator uses the candidate only to decide which choices it draws next, with an ExactDistribution, and not to interpret them. This affects the distribution of the generated values, but not the values that a choice sequence is replayed as, nor shrinking.
