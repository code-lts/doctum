PropertyExample

final class PropertyExample (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

An example of a property: the arguments with which its test method is called, and what the example records while it runs, with assume(), draw(), runStateMachine(), classify(), observe(), and target() of TestCase, which delegate to it, and the throwable that ended it.
