ReflectionTypeRegistry

class ReflectionTypeRegistry (View source)

Centralized registry for Reflection type to Adapter class mappings

This registry eliminates scattered type mapping logic and provides a single source of truth for Reflection object wrapping. When new PHP versions add new Reflection types, only this file needs to be updated.

Uses ::class constants instead of hardcoded strings for better IDE support, refactoring safety, and static analysis.

PHP 5.6+ compatible (::class was introduced in PHP 5.5)
