FalsificationReporter

final class FalsificationReporter (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

Reports how a property was falsified: by an explicit example, whose failure or error is reported as it is, or by a generated example, which is replayed to tell whether it falsifies the property again, whose counterexample is shrunk, and whose minimal counterexample is replayed, as are the simplest counterexamples of the other ways in which the property was falsified while it was shrunk.

A generated example that falsified the property by triggering an issue, and that does not trigger this issue when it is replayed, was not falsified by the issue, which was triggered for another reason than the arguments of the example, because a deprecated class was loaded when the example used it first, for instance: the issue is reported for the property like every other issue of its examples. When the replays do not falsify the property, neither did the example. When they do, in another way, that way is the one for which the counterexample is shrunk and that is reported.
