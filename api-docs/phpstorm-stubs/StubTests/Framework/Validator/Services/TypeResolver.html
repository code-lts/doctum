static string|null resolveVersionAwareType(BasePHPElement $entity, string $phpVersion)

Resolve version-aware type from LanguageLevelTypeAware attribute data.

Finds the highest version key in languageLevelTypes that is <= $phpVersion. Falls back to defaultType when no version entry applies. Returns null when neither languageLevelTypes nor defaultType is set.
