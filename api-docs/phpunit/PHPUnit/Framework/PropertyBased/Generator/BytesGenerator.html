in AbstractGenerator at line 66
final static string labelOf(string $name, string ...$components)

Returns a label that identifies how choices are drawn for a span from the components of the label, for instance the name of the generator and the labels of the generators it is composed of.

The label is computed by sebastian/choice-sequence, so that other tools that use this library label spans whose choices are drawn in the same way with the same label.
