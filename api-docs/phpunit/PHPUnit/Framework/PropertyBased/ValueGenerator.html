ValueGenerator

interface ValueGenerator (View source)

Generates values of type T for the parameters of a property.

Generators are created with the static methods of Generators and composed with the methods of this interface. Generators that are composed this way shrink just like the ones they are composed of.

This interface is not meant to be implemented outside of PHPUnit: an object of any other class that implements it is reported as an error when it is used as a generator.

filter(Closure $predicate)

Returns a generator for the values of this generator that satisfy $predicate. Values that do not satisfy it are generated again. When this fails too often, the example is rejected.
