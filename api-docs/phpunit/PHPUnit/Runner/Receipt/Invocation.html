Invocation

final class Invocation (View source)

internal  This class is not covered by the backward compatibility promise for PHPUnit
 

The first part of the receipt of a test run: what is being run.

It is known before the bootstrap script, the extensions, and the tests are loaded, so that it can be written before any of them can end the process.
