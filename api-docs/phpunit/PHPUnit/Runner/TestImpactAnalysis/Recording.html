string|null changeExecutedOutsideOfTests(PathHasher $hasher)

A file that was executed outside of any test and that is not what it was when it was recorded, or null when there is none.

What was executed outside of any test, while PHPUnit was bootstrapped or while the tests were loaded, for instance, left behind the state every test starts in, so a change to it is a change every test can be affected by.

array testsAffectedByWhatChanged(PathHasher $hasher)

The tests that executed, or that declared that they depend on, something that is not what it was when they were recorded, each with the file that is not what it was.

A test can refer to more than one file that changed. The first one that is found is the one that is reported: it is enough to explain why the test is run, and reporting all of them would say the same thing at greater length.

string|null pathNothingIsKnownAbout(array $paths)

A path that nothing that was recorded accounts for, or null when there is none.

A path that is not among the files that were recorded was not there, or was not first-party code, when the recording was made. A path that was recorded but that no test refers to is a path nothing is known about just the same: that no test executed it does not mean that no test is affected by it, only that executing the tests did not show it.

string|null changeNothingIsKnownAbout(PathHasher $hasher, array $sourceFiles, array $watchedFiles)

A change that nothing that was recorded accounts for, or null when there is none.

A source file that is not among the files that were recorded is a file that was not there, or was not first-party code, when the recording was made, and a watched file that is not among them was not there, or was not watched. A source file or a watched file that changed and that no test refers to is a file that nothing is known about: that no test executed it does not mean that no test is affected by it, only that executing the tests did not show it.
